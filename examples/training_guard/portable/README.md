# Native packet installer scaffolding

The installer and runtime checker require a separately supplied pinned native
packet. Their regression tests cover manifest/input rejection and installation
boundaries. This directory does not include the packet or model/data assets.

Use the [GR00T adapter](../../../docs/GR00T_TRAINING_GUARD.md) for application
integration and the [quick start](../../../docs/QUICKSTART.md) for the included
CPU-only saved-artifact example.
