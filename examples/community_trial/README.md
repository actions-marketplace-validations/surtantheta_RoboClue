# Practitioner trial packet

Use the local preview for familiarization, then select a supported project question independently. This packet is prepared for review; no participant has been contacted and no study or external reuse is reported.

Compare complete jobs using Policy Doctor and competent maintained native tools. Before beginning, agree on the input evidence, intended contract, reference authority, task endpoint, native helper availability and acceptable omissions. Give both routes the same documentation, original artifacts and existing upstream fixes. Randomize route order if the same person does both; record answer exposure and learning effects. A public demo with its answer in the guide is reproducibility practice, not blind diagnosis.

The job endpoint is: inspect actual supported inputs; explain a supported contradiction or evidence gap; verify a supplied correction on the same input; retain a colleague-verifiable check; reproduce it after relocation; apply the unchanged criterion to another original observation. Missing evidence can correctly end in unknown. Do not require a fault or passing correction to exist.

Record dependency/source/data/contract preparation, hands-on and machine time, new helper/analysis/packing code, repairs, failures, interruptions and omitted evidence. Charge new helper authorship when it is required; credit already available helpers and one-command reuse on either route. Share truly identical setup costs only when both routes use that setup. Count colleague and later reuse separately from first use. Preserve unsuccessful or abandoned runs.

Have another reviewer assess the supported answer and evidence without using the tool's status as its sole oracle. Do not equate numerical replay with physical or policy correctness. The capture-sink example performs no policy inference. Ask whether the participant would reuse the result on their project, then record actual voluntary reuse separately from stated intention.

Copy `cost-ledger-template.json` for each route. Leave unavailable observations null. No multiplier, adoption claim or star forecast follows from one internal demo. This packet contains no telemetry, contact workflow or publication automation.
