# RC013 — Declared instructions versus the linked task catalog

Compare an explicit instruction with revision-scoped catalog bytes through
`roboclue check CHECKPOINT --instruction 'TEXT' --language-catalog LOCAL_DATASET`
or the default MCP `preflight_check`.

An absent lexical match is WARNING only. Exact and lexical correspondence
remain distinct, historical provenance remains explicit, and neither establishes
native-token equivalence or a physical capability. Nearest text is never an
automatic semantic correction. Read [the scope and bounds](../LANGUAGE_VOCABULARY.md).
