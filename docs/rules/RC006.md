# RC006: saved statistics describe a consistent finite cohort

For one finite cohort, a mean lies within its min/max; exact zero standard
deviation cannot describe a meaningful nonzero range. The check allows the
reported serialization tolerance: `1e-6` relative plus `1e-8` absolute, with
scale floor 1. These are arithmetic constraints, not a claim that an upstream
project itself has a bug.

[LeRobot's pinned statistics implementation](https://github.com/huggingface/lerobot/blob/146d8474932c8b566717eb2738ba459337ab71c4/src/lerobot/datasets/compute_stats.py)
provides dataset context. RoboClue's detector is
`diagnostics.dataset_statistics_findings`; its `dataset.statistics_inconsistent`
ERROR does not compare saved summaries with actual rows, select a normalization
mode, or certify loader compatibility.

The separate bounded numeric-row comparison can detect stale counts or values:
`dataset.statistics_count_mismatch` checks supported numeric cohort counts;
`dataset.statistics_rows_mismatch` compares supported numeric means, standard
deviations and extrema against complete covered rows. The report names the
features and metrics actually compared. Partial cohorts, unsupported values and
standard-deviation differences explained by native float32 rounding stay
unverified rather than being promoted to PASS or accused as stale statistics.
`dataset.statistics_values_unassessed` carries that incomplete supplied comparison
through the scanner, preflight and health-card verdicts. A separate known mismatch
still takes precedence as ERROR.
Default checks do not recompute image statistics or quantiles.

```sh
roboclue check DATASET --question dataset
```

Default MCP: `dataset_health_card` with `source`. Malformed, missing or unsupported
statistic vectors produce `dataset.statistics_unassessed` UNKNOWN. Legitimate
constant or padded dimensions are not this contradiction. Do not turn missing
statistics into a fabricated ERROR.

Confirm that the summaries were intended to describe the same feature/cohort.
Recompute from retained intended source rows into a separate owned candidate,
preserve the original and rerun the same check. Do not clip the saved mean merely
to silence the result. Unrelated missing evidence can keep the overall dataset
assessment partial even when this specific arithmetic contradiction clears.
