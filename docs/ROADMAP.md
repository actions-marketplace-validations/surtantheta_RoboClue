# Roadmap

The product goal is a reusable verification habit around robot learning: retain
intent, identify supported contradictions and verify corrections.

| Next outcome | Evidence needed |
| --- | --- |
| An unfamiliar researcher completes the workflow on their own pipeline | Independent setup effort, a consequential supported finding, correction verification and false-positive/unknown accounting |
| Broader native training coverage | Original framework/model execution for each claimed profile; healthy, faulty, corrected and unsupported controls |
| More useful upgrade rules | Recurring user incidents, owned-asset binding and native before/after comparisons |
| Physical runtime diagnosis | Actual hardware observations, explicit timing/units/association evidence and preserved application behavior |
| Shared public dataset monitoring | Approved hosting, revision-bound coverage, maintained retention and meaningful author/user feedback |

These are future outcomes, not shipped capabilities or delivery dates. Suggest
a workflow through the issue template with the original artifacts, native tool
behavior and the decision you need to make. A small healthy control is valuable.
